# Jansher Khan: Portfolio

Business Analyst and BI / Power Platform Specialist. A static site (one `index.html` plus media files); no build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Publish with GitHub Pages
1. Settings, Pages, "Deploy from a branch", branch `main`, folder `/ (root)`.
2. The site appears at `https://<username>.github.io/<repo>/`.

## Update content
Everything shown comes from the `portfolioData` object near the top of the script in `index.html`.
`Jansher_Khan_CV.docx` is the file the Download CV button serves.
